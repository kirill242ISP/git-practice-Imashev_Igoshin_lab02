1. НАСТРОЙКА GIT 
----------------------------------------------------------------

git config --global user.name "ваш_ник"
    Указать имя пользователя для подписи коммитов.

git config --global user.email "ваша_почта@yandex.ru"
    Указать email для подписи коммитов.

git config user.name
git config user.email
    Проверить текущие настройки (без --global — для конкретного репозитория).

git version
    Проверить установленную версию Git.

----------------------------------------------------------------
2. СОЗДАНИЕ И ИНИЦИАЛИЗАЦИЯ РЕПОЗИТОРИЯ
----------------------------------------------------------------

mkdir имя_папки
    Создать новую папку.

cd имя_папки
    Перейти в папку.

git init -b main
    Инициализировать новый Git-репозиторий с основной веткой main.

git status
    Показать текущее состояние репозитория (изменённые, новые файлы).

----------------------------------------------------------------
3. ДОБАВЛЕНИЕ ФАЙЛОВ И КОММИТЫ
----------------------------------------------------------------

git add имя_файла
    Добавить конкретный файл в индекс (staging area).

git add .
    Добавить все изменённые и новые файлы в индекс.

git commit -m "Сообщение коммита"
    Создать коммит с описанием изменений.

git commit -am "Сообщение"
    Добавить уже отслеживаемые файлы в индекс и сразу закоммитить.

----------------------------------------------------------------
4. ПРОСМОТР ИСТОРИИ
----------------------------------------------------------------

git log
    Полная история коммитов (хеш, автор, дата, сообщение).

git log --oneline
    Компактная история: сокращённый хеш + сообщение.

git show <хеш>
    Детальная информация о конкретном коммите + diff изменений.

git log --oneline --graph --all
    Графическая история всех веток.

    ВАЖНО: если терминал "завис" и показывает ":" — нажмите q для выхода.

----------------------------------------------------------------
5. РАБОТА С ВЕТКАМИ
----------------------------------------------------------------

git branch
    Показать список локальных веток (* — текущая).

git branch -a
    Показать все ветки: локальные и удалённые.

git switch -c имя_ветки        (современный способ)
git checkout -b имя_ветки      (устаревший, но рабочий)
    Создать новую ветку и переключиться на неё.

git switch имя_ветки
git checkout имя_ветки
    Переключиться на существующую ветку.

git switch -
    Переключиться на предыдущую ветку.

git branch -d имя_ветки
    Безопасно удалить ветку (если изменения слиты).

git branch -D имя_ветки
    Принудительно удалить ветку (даже если не слита).

----------------------------------------------------------------
6. РАБОТА С УДАЛЁННЫМ РЕПОЗИТОРИЕМ (GitFlic / GitHub)
----------------------------------------------------------------

git remote add origin <URL>
    Привязать локальный репозиторий к удалённому.

git remote -v
    Показать список удалённых репозиториев.

git remote set-url origin <новый_URL>
    Изменить URL удалённого репозитория.

git remote remove origin
    Удалить привязку к удалённому репозиторию.

git push -u origin main
    Отправить ветку main на сервер и настроить отслеживание.

git push
    Отправить изменения (если upstream уже настроен).

git push --set-upstream origin feature
    Отправить новую ветку feature на сервер.

git pull
    Загрузить и слить изменения с удалённого репозитория.

git fetch --prune
    Загрузить информацию об удалённых ветках и удалить несуществующие.

8. ПРОБЛЕМЫ И ИХ РЕШЕНИЯ
----------------------------------------------------------------

Проблема 1: git push требует авторизации, ввод старых данных
    Решение:
    - Войти в аккаунт GitFlic/GitHub через браузер по умолчанию.
    - Открыть "Диспетчер учётных данных" Windows → "Учётные данные Windows".
    - Удалить все записи, связанные с GitHub/GitFlic.
    - Повторить git push и ввести актуальные логин/пароль (или токен).

Проблема 2: fatal: The current branch feature has no upstream branch
    Решение:
    git push --set-upstream origin feature

Проблема 3: В терминале появился ":" и не выходит
    Решение:
    - Нажать q (quit) — это pager less.
    - Или Ctrl+C.

Проблема 4: Случайно закоммитил папки bin/obj
    Решение:
    - Создать .gitignore с содержимым:
        bin/
        obj/
        .vs/
    - Удалить их из индекса:
        git rm -r --cached bin obj
    - Сделать новый коммит:
        git commit -m "Remove bin and obj from tracking"

Проблема 5: git push выдаёт "rejected — non-fast-forward"
    Решение:
    - Сначала подтянуть изменения:
        git pull --rebase
    - Затем повторить git push.

Проблема 6: Привязан не тот удалённый репозиторий
    Решение:
    git remote -v
    git remote remove origin
    git remote add origin <правильный_URL>

9. ПОЛЕЗНЫЕ СОЧЕТАНИЯ
----------------------------------------------------------------

# Посмотреть, что изменилось, но ещё не в индексе
git diff

# Посмотреть, что уже в индексе
git diff --staged

# Отменить изменения в файле (до коммита)
git restore имя_файла

# Убрать файл из индекса (но оставить изменения)
git restore --staged имя_файла

# Изменить последний коммит (сообщение или добавить файлы)
git commit --amend
